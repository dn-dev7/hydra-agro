Ferramenta local do Hydra Agro

Preparar a chave Android sem terminal

Selecione o arquivo .jks criado no Android Studio. A conversão para Base64 acontece somente neste navegador.

Privacidade: o arquivo não é enviado ao Hydra Agro, GitHub ou qualquer API. O resultado também não é salvo pelo site.

Abrir Secrets do GitHub
  1. Selecione hydra-agro-release.jks.
  2. Clique em Copiar Base64.
  3. No GitHub, crie o secret ANDROID_KEYSTORE_BASE64 e cole o conteúdo.
  4. Cadastre também as senhas e o alias conforme o guia de publicação.

Feche esta página quando terminar. Não publique o Base64 em commit, issue, comentário, print ou mensagem.
